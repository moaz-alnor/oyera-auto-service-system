# OYERA Auto Service System v1.0.0

**Initial Production Release — 2026-08-07**

OYERA v1.0.0 establishes the first official production baseline for the Oyera Auto Service System. The release brings the workshop's core operational records and workflows into one auditable Django application with role-based access control, PostgreSQL persistence, production deployment support, automated quality gates, and completed user acceptance testing.

## Highlights

- End-to-end customer and vehicle records.
- Quotations and approval workflows.
- Job cards, inspections, notes, workshop execution, and vehicle release.
- Work orders, technician assignments, task lifecycle, and technical notes.
- Inventory reservations, stock issues, returns, and movement history.
- Product and service catalogues with pricing.
- Supplier, purchase-order, goods-receipt, supplier-invoice, and supplier-payment workflows.
- Customer invoices and payment workflows.
- Operational and financial reporting with CSV exports.
- Six operational roles with centrally managed Django permissions.

## Roles

- Administrator
- Manager
- Receptionist
- Senior Technician
- Technician
- Cashier

## Production architecture

The managed cloud deployment supports:

- **Render** — Django web service
- **Neon PostgreSQL** — production database
- **Cloudflare R2** — S3-compatible media-storage configuration
- **Gunicorn** — production WSGI server
- **WhiteNoise** — static-file delivery

The repository also retains a Docker-based production path using PostgreSQL and Caddy.

Live application: https://oyera-auto-service-system.onrender.com/

- HTTPS-aware production settings;
- secure-cookie and HSTS support;
- `pip-audit` dependency auditing;

- GitHub CodeQL;
- Dependabot;
- GitHub secret scanning and push protection;
- Ruff linting and formatting;
- migration drift checks;
- Django system checks;
