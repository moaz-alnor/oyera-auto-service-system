# Support

## Bugs

Use the GitHub **Bug report** template. Include the affected role, workflow, exact steps, expected result, actual result, environment, and sanitized evidence.

## Feature requests

Use the **Feature request** template. Describe the operational problem, proposed solution, affected roles, and acceptance criteria.

## Security issues

Do not open a public issue. Follow [SECURITY.md](SECURITY.md).
