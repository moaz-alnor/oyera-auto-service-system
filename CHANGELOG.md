# Changelog

Significant changes to OYERA Auto Service System are recorded here.

### Added

## Production baseline — August 2026

The current production baseline includes customer and vehicle records, quotations, job cards, workshop execution, technician assignments, inventory, catalogues, purchasing, billing, reports, six-role access control, production hardening, Docker deployment, Render/Neon/R2 deployment support, database backup/restore, automated security scanning, completed role UAT, and final handover documentation.

## Release policy

Future published releases should use:

```text
## [x.y.z] - YYYY-MM-DD
```

Group changes under `Added`, `Changed`, `Fixed`, `Security`, `Deprecated`, and `Removed` as appropriate.
